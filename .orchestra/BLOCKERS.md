# Ограничения и незакрытые проверки

Обновлено 24.10.2026. Итог объединения с `be0df78`: **2226 backend + 12 frontend**,
production build успешен; блокеров по локальной приёмке нет.
Gateway capture без поддержанного источника отвечает 503; полного edge-транспорта
сэмплов в исходной основной ветке нет.
[Текущий отчёт](../docs/MAIN_INTEGRATION_20261024.md).

Предыдущий локальный пакет в срезе `6d2696d` проверил:
**2099 backend + 12 frontend тестов**, production build и синтетический API/WS
сценарий. Блокирующих ошибок в этом срезе не осталось. Новый код из `origin/main`
требует отдельной приёмки после интеграции.
[Источник](metrics/violation-expansion-20261024.json).

До более широких заявлений о готовности остаются следующие ограничения:

- **Внешний LinQ.** Последний пакет, новые правила и specialist-модели заново на
  внешнем TPU не проверены. Исторические стендовые цифры от 24.10.2026 относятся
  к своим моделям и условиям; их нельзя переносить на текущую версию.
- **Полевое качество новых правил.** 13 зарегистрированных типов и синтетические
  тесты подтверждают реализацию. Нет независимой полевой оценки трёх новых правил
  на разных камерах, ракурсах и длительном clean exposure.
- **СИЗ.** Для очков/перчаток нужны отрицательные классы и проверки видимости, привязки к человеку и качества.
  Для обуви нет explicit negative, `no_mask` не равен `no_respirator`; модель
  привязи не добавлена. Unknown или отсутствующий bbox не являются `False`.
- **PPE ROI.** На 6 certain событиях результат хуже full-frame: 4 TP / 2 FN против
  6 TP / 0 FN, при 0 FP на 68.933333 с clean. Оставил экспериментальным;
  [отчёт](metrics/ppe-roi-quality-20261024.json).
- **RF-DETR2XL.** CPU quality на 141 изображении измерено, но raw numeric parity
  failed. Production adapter и LinQ/INT8 не подтверждены; модель не включена.
  [Отчёт](metrics/rfdetr-quality-20261024.json).
- **Границы прежних проверок.** S1 использует 4 certain метки и 120 с positive-video
  exposure без независимых clean-зон. Rabbit-приёмка проверяла транспортные сбои
  и synthetic events, не сквозной model inference/RTSP; доставка edge-клипов
  и длительная retention-проверка остаются отдельными задачами.

Дальнейшую работу веду по [BACKLOG.md](BACKLOG.md). Закрытие каждого пункта требует
своего отчёта и readback; успешный smoke или совпадение округлённых метрик его не заменяют.
