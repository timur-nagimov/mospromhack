# Зазеркалье — видеоаналитика нарушений ТБ на LinQ TPU

Хакатон «Открой#Моспром», кейс LinQ. Веб-сервис в реальном времени находит нарушения техники безопасности на видео с камер: вход в опасную зону, отсутствие СИЗ, падение, опасное сближение с техникой и другие. Инференс нейросетей идёт на ускорителе LinQ TPU.

Статус: идёт разработка. Полный README с запуском, архитектурой и замерами появится к сдаче.

## Где что лежит

- `docs/CONTRACTS.md` — контракты модулей, HTTP API и владение путями.
- `.orchestra/` — состояние разработки: `STATE.md`, `BACKLOG.md`, `DECISIONS.md`, `BLOCKERS.md`, `LOG.md`.
- `guard/` — бэкенд (Python 3.11, FastAPI); `frontend/` — веб-интерфейс; `ml/` — модели; `tpu/` — компиляция и замеры на LinQ.

## Как работать параллельно с агентами

- Агенты коммитят в свои ветки (`codex/*`, `worktree-*`), после проверки оркестратор вливает их в `main` и пушит. В начале каждой итерации оркестратор подтягивает `main` из GitHub.
- Чтобы не было конфликтов, работай в своей ветке или в путях, которые в `docs/CONTRACTS.md` («Владение путями») не закреплены за агентами. Задачи и их статусы — в `.orchestra/BACKLOG.md`.
- Данные (`data/`), модели (`models/`), скачанные SDK (`vendor/`) и `.env` в git не попадают.
