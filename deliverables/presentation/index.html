@register_rule
class CrowdingRule(RulePlugin):
    type = "crowding"
    title = "Скопление людей в зоне"
    required_models = frozenset({"det"})
    params_schema = {...}  # по ней UI строит форму

    def evaluate(self, ctx) -> list[Violation]:
        # только кадр; окно и дубли — в EventManager
        limit = int(self.cfg.params.get("max_people", 3))
        out = []
        for zone in self.camera.zones:
            if not is_zone_active(zone, ctx.ts):
                continue
            n = sum(in_zone(t, zone) for t in ctx.people)
            if n > limit:
                out.append(self.violation(
                    ctx, zone_id=zone.zone_id))
        return out

Что дальше Э · Н

Пилот → масштаб узлами → интеграции

Шаг 1

Пилот на 2–3 самых опасных участках

  • 1–2 узла LinQ, зоны и правила настраивает специалист ОТ
  • Журнал меряет эффект сам: пресечённые нарушения, доля ложных, динамика по сменам
Шаг 2

Масштабирование узлами

  • Число узлов — по формуле из замеров, а не по обещаниям
  • Шлюз сводит площадки в общий журнал; фильтры по полю site уже есть
Шаг 3

Интеграции и качество

  • СКУД, MES, наряды-допуски, мессенджеры, световой и звуковой сигнал у зоны
  • Дообучение на решениях оператора, отчёты по смене
