@register_rule
class CrowdingRule(RulePlugin):
    type = "crowding"
    title = "Скопление людей в зоне"
    required_models = frozenset({"det"})
    params_schema = {...}  # по ней UI строит форму

    def evaluate(self, ctx) -> list[Violation]:
        # только кадр; окно и дубли — в EventManager
        limit = int(self.cfg.params.get("max_people", 3))
        out = []
        for zone in self.camera.zones:
            if not is_zone_active(zone, ctx.ts):
                continue
            n = sum(in_zone(t, zone) for t in ctx.people)
            if n > limit:
                out.append(self.violation(ctx, zone_id=zone.zone_id))
        return out

Сверка обязательна
Precision и recall здесь — совпадение TPU с CPU той же модели (класс и IoU ≥ 0.5), а не с разметкой. Каждую новую программу сверяем так же
Потолок Sigmoid
Масштаб выхода калибруется по максимуму на калибровочных кадрах. Огня в них почти не было: потолок 0.42 / 0.50 / 0.57 по страйдам. Порог слоя 1.0 → шаг уверенности 1/127, Δ −0.19 → −0.05
Порог под int8
Уверенность после int8 ниже на 0.02–0.05. Порог det на TPU 0.25 вместо 0.35: recall 0.90 → 0.95 на отложенных кадрах. Дообучение квантования почти ничего не дало
